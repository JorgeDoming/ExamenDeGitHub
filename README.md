# ExamenDeGitHub
El equipo de desarrollo de la plataforma web "Cine Ticket" esta iniciando el ciclo de construccion. En la reunion de relevamiento, 
el gerente del cine les comenta lo siguiente:
"Actualmente las fila en la taquilla son enormes los fines de semana y perdemos ventas
porque la gente se frustra y se va. Necesitamos que los clientes pueden a la web,
ver la catelera del dia y comprar sus entradas eligiendo los asientos especificos, para
que peudan llegar las nuevas peliculas de la semana y modificar los precios de las entradas segun 
si es 2D o 3D, para poder mantener el catalogo actualizado sin depender de un 
progrmador"
